Sales Order Lifecycle

How a sales order moves from creation by a sales rep through approval (or hold / rejection) and into the fulfilment queue. Every order gets a unique sequential number (SO-YYYY-000001) and is always tied to a specific outlet and its assigned warehouse.

Order Number

Auto-assigned sequential number per year: SO-2026-000001, SO-2026-000002…

Outlet ↔ Warehouse

Every outlet is pre-mapped to a warehouse. The order inherits this mapping automatically.

Priority Levels

Low · Medium · High · Critical — used for dispatch queue prioritisation.

Hold Flow

An order on hold can be approved or rejected. It cannot be dispatched while held.

2

Dispatch Flow

Once an order is approved, the warehouse manager packs and dispatches items with full logistics details (transporter, vehicle, LR number). Each dispatch records serial numbers per line and deducts stock from the warehouse in real time.

Idempotent Dispatch

Duplicate dispatch requests (same idempotency key) are safely rejected — no double-deductions.

Serial Number Tracking

Each dispatched unit can carry a serial number. Serials feed directly into the Service module for warranty lookups.

Partial Dispatch

You can dispatch a subset of ordered quantity. The remaining quantity stays pending for a follow-up dispatch.

Optimistic Locking

Concurrent dispatch attempts are safely blocked — the system uses row-level locking to prevent over-dispatching.

3

Invoice & Payments Flow

Invoices are generated automatically when an order is approved. Tax charges are applied from a central configurable rate card. Payments from outlets are recorded and automatically allocated to the oldest outstanding invoices first (FIFO), keeping AR balances accurate.

Auto-Invoice

No manual step needed — approval triggers invoice creation instantly with the correct tax calculations.

Configurable Tax Rates

GST, freight, handling — any charge type (% or fixed) can be configured in the admin panel and applied globally.

FIFO Allocation

A payment is always applied to the oldest unpaid invoice first, keeping AR aging clean automatically.

PDF Export

Every invoice can be downloaded as a PDF directly from the dashboard for sharing with outlets.

4

Service Complaint & Warranty Flow

After-sales service is managed through a structured complaint lifecycle. Each complaint is tracked from initial raising through field visits, test reports, and warranty decisions (replacement or rejection). Warranty replacements automatically create a fulfillment order that flows back through the dispatch pipeline.

Serial Lookup

Type any serial number to see its full history: which order it shipped on, which outlet received it, and all linked complaints.

Warranty Replacement

Approved warranty claims auto-create a zero-value sales order (no invoice). The replacement flows through the normal dispatch pipeline.

Full Audit Trail

Every action (assign, visit, test, decision) is logged with actor, timestamp, and status transition — nothing is ever lost.

5

Field Sales Agent Tracking (Field Sense)

Field Sense turns every sales agent's mobile device into a real-time tracking node. Shifts start and close automatically. GPS trails are streamed live to the admin dashboard. Outlet visits are logged with timestamps and location so managers get accurate field activity reports without relying on manual check-ins.

Auto Shift Management

Shifts start and close without any manual action. A cron job checks every minute; the ±2-min window handles clock drift on devices.

GPS Trail Simplification

The Ramer-Douglas-Peucker (RDP) algorithm removes redundant GPS points before storage, cutting data volume without losing route fidelity.

Live Map

Managers see all field agents on a real-time map the moment they open the dashboard — updates pushed via Server-Sent Events (SSE).

Offline Resilience

The mobile app queues GPS points locally when offline and syncs the backlog automatically when connectivity is restored.
